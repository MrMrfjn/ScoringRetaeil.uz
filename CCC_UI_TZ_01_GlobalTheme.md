# CCC UI — ТЗ 01: Глобальная тема и стеклянный стиль

## Цель
Перевести весь интерфейс CCC на единый современный «iOS glass» стиль (тёмная/светлая тема) без ухудшения производительности.

## Требования по производительности

- Использовать **только CSS-анимации** (`transition`, `transform`, `opacity`), без тяжёлых JS-циклов.
- Эффекты blur применять **только к крупным контейнерам** (nav, карточки, модальные блоки), а не к отдельным строкам таблиц.
- Проверить, что на страницах с большими таблицами (портфель, аналитика) скролл остаётся плавным.
